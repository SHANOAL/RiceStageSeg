# RiceStageSeg
## RiceStageSeg：A Multimodal Benchmark Dataset for Semantic Segmentation of Rice Growth Stages

This repository hosts **RiceStageSeg**, a dataset and baseline code for rice growth-stage segmentation.  
The dataset was originally shared at [Baidu NetDisk](https://pan.baidu.com/s/14aJjnKKZ8gxUKInJa39zEA?pwd=ydek) (pwd: `ydek`).  
We re-host it here to make access easier for researchers outside China.
